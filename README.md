# brickrail-2

A layout editor and train-control simulation for LEGO train layouts, driving
Pybricks hubs over Bluetooth.

- The design: [`docs/design/`](docs/design/README.md)
- Decisions and reasoning: [`docs/rfc/`](docs/rfc/)
- Current state and todos: [`docs/STATUS.md`](docs/STATUS.md)

Build and test with `nix develop -c cargo test`.
